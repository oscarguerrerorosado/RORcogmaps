# RORcogmaps — Reward Overrepresented Hippocampal Cognitive Maps

## ⚠️ Active Research Repository

This repository is under active development. Experiments 1, 2, and 3 are producing results. Experiments 4 and 5 are ongoing. Code and structure will evolve as the project progresses.

---

## Abstract

Hippocampal place cells do not represent space uniformly. When an agent performs a memory-demanding reinforcement learning task, place fields transition from a sparse spatial distribution to a clustering near reward locations, a phenomenon known as reward overrepresentation. This repository investigates the computational mechanisms underlying this remapping from the perspective of the hippocampal-VTA loop, and asks whether reward overrepresented cognitive maps confer measurable advantages for agents performing reinforcement learning tasks.

The hippocampal autoencoder used across experiments is based on the model introduced in:

Amil, A. F., et al. (2024) **A Hippocampal Model for Behavioral Sequence Replay**
 — *arXiv preprint*. [https://arxiv.org/abs/2405.14600](https://arxiv.org/abs/2405.14600)

and extended to motivational representations in:

Guerrero Rosado, O., et al. (2025). **Motivational Cognitive Maps Allow Robot Biomimetic Autonomy**. In *2025 IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS)* (pp. 14402-14408). IEEE. [https://ieeexplore.ieee.org/abstract/document/11246932](https://ieeexplore.ieee.org/abstract/document/11246932)

## 🧠 Research Questions

This project is organized around five experiments:

**Experiment 1 — Global Novelty Signals in the Hippocampal Autoencoder**
A hippocampal autoencoder is trained sequentially across three visually different T-maze environments. Global novelty signals are analyzed as training transitions from one environment to the next.

**Experiment 2 — Local Novelty Signals in the Hippocampal Autoencoder**
The autoencoder is trained on a Double T-maze. Local novelty signals are analyzed when a novel object is introduced into the environment after training.

**Experiment 3 — Novelty-driven Oversampling Leads to Reward Overrepresentation**
Inspired by hippocampal physiology, the trained Double T-maze model is retrained with a sampling bias toward images near the reward location. Place fields cluster near the reward as a result. A control model trained without sampling bias serves as comparison.

**Experiment 4 (ongoing) — Reward Overrepresented World Models Enhance Reinforcement Learning Performance**
The reward overrepresented cognitive maps from Experiment 3 are deployed in an embodied reinforcement learning agent in a Webots simulation. This experiment will be hosted in a dedicated repository.

**Experiment 5 (ongoing) — Reward Overrepresentation Distorts World Model Geometry**
Analysis of how reward overrepresentation alters the geometric structure of the learned latent space.

## 📘 Notebooks

### Experiment 1 — Global Novelty Signals

- **`serial_train_autoencoder.ipynb`**
  Trains the hippocampal autoencoder sequentially across three T-maze environments. Supports batch training of multiple model instances.

- **`serial_train_autoencoder(Control).ipynb`**
  Trains the autoencoder across different datasets of the same T-maze version (v1). Control condition for Experiment 1.

- **`Ratemap_extraction.ipynb`**
  Extracts and saves model embeddings at every training epoch to accelerate downstream analysis. Run this before the analysis notebooks.

- **`Individual_exp_ratemap_analysis.ipynb`**
  Analyzes the performance progression of a single autoencoder instance. Useful for extracting example ratemaps and input reconstructions.

- **`Group_exp_ratemap_analysis.ipynb`**
  Analyzes the joint performance progression of a set of autoencoders. Reports mean and standard deviation metrics across instances.

### Experiment 2 — Local Novelty Signals

- **`DoubleTmaze_novelty_detection.ipynb`**
  Trains and analyzes how the hippocampal autoencoder signals novelty when a local environmental change is applied by introducing a new object into the Double T-maze.

### Experiment 3 — Reward Overrepresentation

- **`train_autoencoder_overrepresentation.ipynb`**
  Trains a hippocampal autoencoder on the Double T-maze. After initial training, a novel object is introduced near the reward location and the model is retrained with a sampling bias toward reward-proximal images. A control model undergoes the same retraining without sampling bias.
